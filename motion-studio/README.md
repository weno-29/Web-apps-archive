# Motion Studio

画像や動画にカメラモーション・フィルター・パーティクルを重ねて、短い映像として書き出すブラウザアプリです。インストール不要、素材はサーバーに送信されません。

## 使い方

1. 画像（JPG / PNG / WebP）または動画（MP4 / MOV / WebM）を選ぶ
2. カメラモーション、強度、フィルター、パーティクルを選ぶ
3. 長さ（3〜12秒）と解像度（720p / 1080p）を選ぶ
4. 「動画を書き出す」で録画・ダウンロード

## できること

- カメラモーション：ズームイン / ズームアウト / パン左右 / ティルト / オービット
- フィルター：シネマ / ウォーム / クール / モノクロ / VHS / ドリーム
- パーティクル：塵 / 雪 / 雨 / ボケ光
- AI提案（任意）：Anthropic API キーを入力すると、Claude が素材とプロンプトから設定を提案

## 制約

- Kling AI などの動画生成AIとは仕組みが異なります。被写体そのものを動かす生成は行わず、素材全体に映像効果をかける方式です。
- 書き出しはリアルタイム録画のため、設定した秒数だけ時間がかかります。
- 書き出し形式はブラウザに依存します（Chrome 系は WebM、Safari 系は MP4）。
- AI提案の API キーはブラウザの localStorage に保存され、`api.anthropic.com` にのみ送信されます。共用端末では入力しないでください。API 利用料はキーの持ち主に発生します。
